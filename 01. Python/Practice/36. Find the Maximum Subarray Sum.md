# Method Bruteforce
```python
def finmax(nums):
    maxi = float('-inf')
    for i in range(0, len(nums)):
            total = 0
        for j in range(i, len(nums)):
            total += nums[j]
            maxi = max(maxi, total)
    return maxi
print(finmax([-2, -1, -3, 4, -1, 2, 1, -5, 4]))
```
### Time Complexity: O(N*2)
### Time Complexity: O(1)

# # Method Optimal
```python
def finmax(nums):
    maxi = float('-inf')
    total = 0
    for i in range(0, len(nums)):
        total += nums[i]
        maxi = max(maxi, total)
        if total < 0:
            total = 0
    return maxi
print(finmax([-2, -1, -3, 4, -1, 2, 1, -5, 4]))
```
# ### Time Complexity: O(N)
# ### Time Complexity: O(1)
