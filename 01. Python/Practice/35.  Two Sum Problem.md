# Method Bruteforce
```python
def finsum(nums, k):
    for i in range(0, len(nums)-1):
        for j in range(i+1, len(nums)):
            if nums[i] + nums[j] == k:
                return i, j

print(finsum([5, 9, 1, 2, 4, 15, 6, 3], 13))
```
### Time Complexity: O(N*2)
### Time Complexity: O(1)

# Method Optimal
```python
def finsum(nums, k):
    hashs = {}
    for i in range(0, len(nums)):
        fin = abs(nums[i] - k)
        if fin in hashs:
            return hashs[fin], i    
        hashs[nums[i]] = i
    
print(finsum([5, 9, 1, 2, 4, 15, 6, 3], 13))
```
### Time Complexity: O(N)
### Time Complexity: O(N)
