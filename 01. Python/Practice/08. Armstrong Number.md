## Is Armstrong
# ```python   
def pal(n):
    num = n
    total = 0
    while num > 0:
        l = num % 10
        total += l*l*l
        num = num // 10 
    return total == n

print(pal(153))
# ```
output: True
### Time Complexity: O(log10(N))
### Time Complexity: O(1)
