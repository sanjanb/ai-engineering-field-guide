# Method - Bruteforce
```python
def finmax(nums):
    maxi = 0
    for i in range(0, len(nums)):
        for j in range(i+1, len(nums)):
            if nums[j] < nums[i]:
                profit = (nums[i] - nums[j])
            maxi = max(maxi, profit)
    if maxi <= 0:
        return 0
    else:
        return maxi
print(finmax([7, 2, 1, 5, 6, 4, 8]))
```

### Time Complexity: O(N*2)
### Time Complexity: O(1)

def finmax(nums):
    maxp = 0
    minp = float("inf")
    for i in range(0, len(nums)):
        minp = min(minp, nums[i] )
        maxp = max(maxp, nums[i]- minp)
    return maxp
print(finmax([7, 2, 1, 5, 6, 4, 8]))
```

### Time Complexity: O(N)
### Time Complexity: O(1)
