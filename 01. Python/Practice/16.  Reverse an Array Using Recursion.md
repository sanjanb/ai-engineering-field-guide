
## Method 1: Functional Recursion (Cleanest)
This approach slices the list down, takes the last element, and appends the recursive result of the rest.
```python
def reverse_list(lst):
    # Base Case: An empty list or single-element list is already reversed
    if len(lst) <= 1:
        return lst
    
    # Recursive Step: Last element + reverse of everything else
    return [lst[-1]] + reverse_list(lst[:-1])

print(reverse_list([1, 2, 3, 4, 5]))  # Output: [5, 4, 3, 2, 1]
```
## Complexity for Method 1:

* Time Complexity: O(N²) — The function is called N times, but slicing a list lst[:-1] takes O(N) time on every call because Python copies the elements.
* Space Complexity: O(N²) — Due to both the recursive call stack memory O(N) and the creation of new sliced list copies at each stack frame.

## Method 2: Two-Pointer Recursion (Optimised & In-Place)
To achieve ideal efficiency, you can pass two pointers (left and right) and swap the elements at those positions, moving inward until they meet in the middle.
```python
def reverse_in_place(lst, left=0, right=None):
    # Initialise right pointer on the first call
    if right is None:
        right = len(lst) - 1
        
    # Base Case: When pointers meet or cross, the list is fully reversed
    if left >= right:
        return lst
    
    # 1. Action: Swap the elements
    lst[left], lst[right] = lst[right], lst[left]
    
    # 2. Recursive Call: Move pointers closer to the middle
    return reverse_in_place(lst, left + 1, right - 1)
my_list = [1, 2, 3, 4, 5]
print(reverse_in_place(my_list))  # Output: [5, 4, 3, 2, 1]
```
## Complexity for Method 2:

* Time Complexity: O(N) — The function processes N/2 pairs. Swapping elements by index takes O(1) constant time, making it significantly faster than slicing.
* Space Complexity: O(N) — No new list copies are made because it modifies the original list directly (in-place). The memory is purely used by the N/2 stack frames on the call stack.
