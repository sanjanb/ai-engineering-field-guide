## Last to first
```python
def ext(n):
    num = n
    digits = []
    while num > 0:
        l = num % 10
        digits.append(l)
        num = num // 10
    return digits

print(ext(1234))
```

## first to last
```python
def ext(n):
    num = n
    digits = []
    while num > 0:
        l = num % 10
        digits.insert(0, l)
        num = num // 10
    return digits

print(ext(1234))
```python
