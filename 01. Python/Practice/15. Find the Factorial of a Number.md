To find the factorial of a number using recursion, you can use the Functional Recursion approach.
Mathematically, the factorial of a number $N$ (written as $N!$) is the product of all positive integers less than or equal to $N$. The problem can be broken down into a simple recursive formula:
$$\text{factorial}(N) = N \times \text{factorial}(N - 1)$$ 
Here is the implementation of finding a factorial recursively:
```python
def factorial(n):
    # 1. Base Condition: The simplest version of the problem with a known value
    if n == 0 or n == 1:
        return 1
    
    # 2. Recursive Step: N multiplied by the factorial of (N - 1)
    return n * factorial(n - 1)

print(factorial(4))  # Output: 24 (4 * 3 * 2 * 1)
```

## Dry Run & Stack Visual (For factorial(4))
When you run factorial(4), the code builds up the call stack as it goes down, and then performs the multiplications as it climbs back up:
```text
1. Going Down (Building the Stack):
factorial(4) ──> waits for 4 * factorial(3)
  factorial(3) ──> waits for 3 * factorial(2)
    factorial(2) ──> waits for 2 * factorial(1)
      factorial(1) ──> Base Case hit! Returns 1 instantly.

2. Coming Up (Unwinding and Multiplying):
    factorial(2) resumes ──> 2 * 1 = 2
  factorial(3) resumes ──> 3 * 2 = 6
factorial(4) resumes ──> 4 * 6 = 24

```
### Time Complexity: $O(N)$
### Space Complexity: $O(N)$
