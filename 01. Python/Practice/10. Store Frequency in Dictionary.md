## Method 1 - store freq
```python
def freq(nums):
    f = {}
    for i in range(0, len(nums)):
        if nums[i] in f:
            f[nums[i]] += 1
        else:
            f[nums[i]] = 1
    return f

print(freq([5, 6, 7, 7, 1, 9, 111, 1, 1, 5, 1, 1]))
```
### Time Complexity: O(N)
### Time Complexity: O(N)

## Method 2 - store freq
```python
def freq(nums):
    hashmap = {}
    for i in range(0, len(nums)):
        hashmap[nums[i]] = hashmap.get(nums[i], 0) + 1
    return hashmap

print(freq([5, 6, 7, 7, 1, 9, 111, 1, 1, 5, 1, 1]))
```
### Time Complexity: O(N)
### Time Complexity: O(1)
