## 1. Basic Recursion & The Base Case
To prevent a function from running forever and crashing your program with a RecursionError (Stack Overflow), every recursive function needs two things:

   1. Base Case: A conditional statement that stops the recursion.
   2. Recursive Case: The part where the function calls itself with a modified input, moving closer to the base case.

## 2. Head Recursion
In Head Recursion, the function performs its core processing or action before making the recursive call. It processes data as it goes down into the call stack.
## Example: Countdown
```python
def head_countdown(n):
    # 1. Base Case
    if n <= 0:
        return
        
    # 2. Action happens BEFORE the recursive call
    print(n) 
    
    # 3. Recursive Call (Head)
    head_countdown(n - 1)

head_countdown(3)
```


## How it executes:
```text
head_countdown(3) -> Prints 3, then calls head_countdown(2)
  head_countdown(2) -> Prints 2, then calls head_countdown(1)
    head_countdown(1) -> Prints 1, then calls head_countdown(0)
      head_countdown(0) -> Base case hit! Returns nothing.

Console Output:

3
2
1
```
## 3. Tail Recursion (with Backtracking behavior)
In Tail Recursion, the recursive call is made first, and the actual action or processing happens after the function returns from the recursive call. It processes data on the way up, as the call stack unwinds (backtracks).
## Example: Count Up
```python
def tail_countdown(n):
    # 1. Base Case
    if n <= 0:
        return
        
    # 2. Recursive Call happens FIRST
    tail_countdown(n - 1) 
    
    # 3. Action happens AFTER the recursive call (during backtracking)
    print(n)

tail_countdown(3)
```
## How it executes (The Stack Visual):
The program is forced to pause the printing action because it must resolve the inner function calls first. It builds a stack up to the base case, and only prints when it starts collapsing backwards:
```text
Step 1: tail_countdown(3) pauses -> calls tail_countdown(2)
Step 2:   tail_countdown(2) pauses -> calls tail_countdown(1)
Step 3:     tail_countdown(1) pauses -> calls tail_countdown(0)
Step 4:       tail_countdown(0) hits base case and returns!
Step 5:     tail_countdown(1) resumes -> Prints 1
Step 6:   tail_countdown(2) resumes -> Prints 2
Step 7: tail_countdown(3) resumes -> Prints 3

Console Output:

1
2
3
```
