## Bruteforce - return list of factors   
```python   
def fac(n):
    factors = []
    for i in range(1, n+1):
        if n % i == 0:
            factors.append(i)
    return factors

print(fac(20))
```
# output: True
### Time Complexity: O(N)
### Time Complexity: O(k)

## Better Solution
```python   
def fac(n):
    factors = []
    for i in range(1, (n//2)+1):
        if n % i == 0:
            factors.append(i)
    factors.append(n)
    return factors

print(fac(20))
```
# output: False
### Time Complexity: O(N/2)
### Time Complexity: O(k)

## Optimal Solution
```python   
from math import sqrt
def fac(n):
    factors = []
    for i in range(1, int(sqrt(n))+1):
        if n % i == 0:
            factors.append(i)
            if n // i != i:
                factors.append(n // i)
    factors.sort()
    return factors

print(fac(20))
```
# output: False
### Time Complexity: O(sqrt(N) + O(NlogN)
### Time Complexity: O(k)
