## Bruteforce - count the nuber
```python
def freq(n, m):
    for num in n:
        count = 0
        for x in m:
            if x == num:
                count += 1
        print(count)

print(freq([5, 3, 2, 2, 1, 5, 5, 7, 5, 10], [10, 111, 1, 9, 5, 67, 2]))
```
### Time Complexity: O(N*M)
### Time Complexity: O(1)

## optimal
```python
def freq(n, m):
    hashlist = {}
    for num in n:
        hashlist[num] = hashlist.get(num, 0) + 1
    for num in m:
        print(hashlist.get(num, 0))

print(freq([5, 3, 2, 2, 1, 5, 5, 7, 5, 10], [10, 111, 1, 9, 5, 67, 2]))
```
### Time Complexity: O(N+M)
### Time Complexity: O(1)
