# Method Bruteforce
```python
def longg(nums):
    maxi = 0
    for i in range(0, len(nums)):
        count = 1
        j = 1
        while nums[i]+j in nums:
            count += 1
            j += 1
        maxi = max(maxi, count)
    return maxi
    
print(longg([1, 99, 101, 98, 2, 5, 3, 100, 1, 1]))
```
### Time Complexity: O(N*2)
### Space Complexity: O(1)

# Method Better solution
```python
def longg(nums):
    count = 0
    longest = 0
    least = float("-inf")
    nums.sort()
    
    for i in range(0, len(nums)):
        if nums[i]-1 == least:
            count += 1
            least = nums[i]
        elif nums[i]-1 != least:
            count = 1
            least = nums[i]
        longest = max(longest, count)
        
    return longest
            
print(longg([1, 99, 101, 98, 2, 5, 3, 100, 1, 1]))
```
### Time Complexity: O(N)
### Space Complexity: O(1)
