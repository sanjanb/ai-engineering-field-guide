## Method 1: Using Recursion (Two-Pointer Approach)
To check a string recursively, you compare the first and last characters. If they match, you strip them off and pass the remaining inner string to the next recursive call.
```python
def is_palindrome_recursive(s, left=0, right=None):
    # Initialize the right pointer on the first call
    if right is None:
        right = len(s) - 1
        
    # Base Case: If pointers meet or cross, all characters matched perfectly
    if left >= right:
        return True
        
    # If characters at the pointers don't match, it's not a palindrome
    if s[left] != s[right]:
        return False
        
    # Recursive Case: Move pointers inward
    return is_palindrome_recursive(s, left + 1, right - 1)

print(is_palindrome_recursive("radar"))  # Output: True
print(is_palindrome_recursive("hello"))  # Output: False
```
## Complexity Analysis:

* Time Complexity: O(N) — The function checks at most N/2 pairs of characters.
* Space Complexity: O(N) — Requires N/2 active stack frames on the call stack memory.

## Method 2: Using a Loop (While Loop)
This is the most memory-efficient approach. It uses two pointers moving toward the center inside a while loop, completely avoiding the memory overhead of a recursive call stack.
```python
def is_palindrome_loop(s):
    left = 0
    right = len(s) - 1
    
    while left < right:
        if s[left] != s[right]:
            return False  # Exit early the moment a mismatch is found
        left += 1
        right -= 1
        
    return True  # If the loop finishes, it's a palindrome

print(is_palindrome_loop("madam"))  # Output: True
print(is_palindrome_loop("apple"))  # Output: False
```
## Complexity Analysis:

* Time Complexity: O(N) — The loop iterates at most N/2 times.
* Space Complexity: O(1) — Constant space. No extra memory or stack frames are created.

## The Pythonic One-Liner Shortcut
In a real-world Python project, you wouldn't use a loop or recursion at all. You would use string slicing to compare the string directly to its reversed self:

def is_palindrome_fast(s):
    return s == s[::-1]

(Note: This runs in O(N) time but takes O(N) space to create the reversed copy of the string).
