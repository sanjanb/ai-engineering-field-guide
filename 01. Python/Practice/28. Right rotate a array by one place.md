# Method - Bruteforce
```python
def rev(n):
    n[:] = n[-1:] + n[:-1]
    return n

print(rev([1, 2, 3, 4, 5, 6, 7]))
```

### Time Complexity = O(N)
### Time Complexity = O(N)

# Method - optimal
```python

def rev(n):
    temp = n[-1]
    for i in range(len(n)-2, -1, -1):
        n[i+1] = n[i]
    n[0] = temp
    return n

print(rev([1, 2, 3, 4, 5, 6, 7]))
```

### Time Complexity = O(N)
### Time Complexity = O(1)
