### 1. What is a 2D Matrix / 2D List?

A matrix is a collection of elements organized in rows and columns ($R \times C$). In Python, a 2D matrix is represented using a **nested list** (a list containing sub-lists).

```python
# Representing a 3x3 Matrix
matrix = [
    [5, 20, 3],     # Row 0
    [7, -10, 9],    # Row 1
    [1, -52, 6]     # Row 2
]

# Finding Dimensions
rows = len(matrix)          # 3 rows
cols = len(matrix[0])       # 3 columns
total_elements = rows * cols # 9 elements
```

---

### 2. How to Iterate Through a 2D Matrix

To access each element individually, nested loops are used where `i` tracks the row index and `j` tracks the column index.

```python
rows = len(matrix)
cols = len(matrix[0])

# Traversing row-by-row
for i in range(rows):
    for j in range(cols):
        print(matrix[i][j], end=" ")
    print()  # Moves to the next line after completing a row
```

---

### 3. Pattern Exercises & Index Relationships

#### Upper Triangle Pattern (`j >= i`)

To print only the upper triangular elements (including the diagonal) and replace the rest with `*`:

```python
for i in range(rows):
    for j in range(cols):
        if j >= i:
            print(matrix[i][j], end=" ")
        else:
            print("*", end=" ")
    print()
```

#### Other Matrix Indexing Rules

* **Lower Triangle:** `i >= j`
* **Main Diagonal:** `i == j`
* **Anti-Diagonal (Secondary Diagonal):** `i + j == rows - 1`

### 4. Transpose of a Matrix

Transposing a matrix flips it over its main diagonal, swapping its rows and columns ($M \times N \rightarrow N \times M$).

```python
# Example for a 2x3 Matrix
nums = [
    [5, 9, 1],
    [2, 3, 7]
]

r = len(nums)      # 2
c = len(nums[0])   # 3

# Initialize a new matrix with swapped dimensions (3x2) full of zeros
result = [[0] * r for _ in range(c)]

# Populate transposed values
for i in range(r):
    for j in range(c):
        result[j][i] = nums[i][j]

print(result)
# Output: [[5, 2], [9, 3], [1, 7]]
```
