# Method Bruteforce

```python

def miss(nums):
    n = len(nums)
    for i in range(0, n+1):
        if i not in nums:
            return i

print(miss([1, 0, 3, 4]))
```

### Time Complexity: O(N*2)
### Space Complexity: O(1)

# Method Better Solution

```python

def miss(nums):
    dict = {}
    n = len(nums)
    for i in range(0, n+1):
        dict[i] = dict.get(i , 0)
    for i in nums:
        dict[i] = dict.get(i, 0) + 1
    for key, value in dict.items():
        if value == 0:
            return key

print(miss([1, 0, 3, 4]))
```

### Time Complexity: O(3N) ~ O(N)
### Space Complexity: O(N)

# Method Optimal

```python

def miss(nums):
    total = 0
    n = len(nums)
    for i in range(0, n):
        total += nums[i]
    return n*(n+1)//2 - total

print(miss([1, 0, 3, 4]))
```

### Time Complexity: O(N)
### Space Complexity: O(1)
