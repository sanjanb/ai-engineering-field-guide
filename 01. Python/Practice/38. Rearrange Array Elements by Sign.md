# Method Bruteforce
```python
def rear(nums):
    pos = []
    neg = []
    for i in range(0, len(nums)):
        if nums[i] >= 0:
            pos.append(nums[i])
        else:
            neg.append(nums[i])

    for i in range(0, len(pos)):
        nums[2*i] = pos[i]
        nums[(2*i)+1] = neg[i]
    return nums        

print(rear([5, 10, -3, -1, -10, 6]))
```

### Time Complexity: O(N)
### Time Complexity: O(N)

# Method Optimal
```python
def rear(nums):
    result = [0 for _ in range(len(nums))]
    p= 0
    n = p+1
    for i in range(0, len(nums)):
        if nums[i] >= 0:
            result[p] = nums[i]
            p += 2
        else:
            result[n] = nums[i]
            n += 2
    return result

print(rear([5, 10, -3, -1, -10, 6]))
```

### Time Complexity: O(N)
### Time Complexity: O(1)
