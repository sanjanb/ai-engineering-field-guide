# Method - Bruteforce
```python
def dup(n):
    freq = {}
    for i in range(0, len(n)):
        freq[n[i]] = 0
    j = 0
    for key in freq:
        n[j] = key
        j += 1
    return j

print(dup([1, 3, 4, 5, 5, 6, 7]))
```

### Time Complexity = O(N+N) -> O(2N) ~ O(N)
### Time Complexity = O(N)


# Method - Optimal
```pytohn

def dup(n):
    i = 0
    if len(n) == 1:
        return 1
    for j in range(i+1, len(n)):
        if n[i] != n[j]:
            i += 1
            n[i], n[j] = n[j], n[i]

    return n

print(dup([1, 3, 4, 5, 5, 6, 7]))
```

### Time Complexity = O(N)
### Time Complexity = O(1)
