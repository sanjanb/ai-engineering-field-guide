# Methon - 1:

```python
def largest(n):
    lar = 0
    for i in n:
        if i > lar:
            lar = i
    return lar  

print(largest([1, 2, 5, 7, 7,4]))
```

## what if all the numbers are negetive values, then it will take 0 as largest which was never in the list

```python
def largest(n):
    lar = n[0]
    for i in n:
        lar = max(lar, i)
    return lar

print(largest([1, 2, 5, 7, 7,4]))
```

### Time complexity = O(N)
### Space complexity = O(1)

# Method - 2

```python
def largest(n):
    lar = float("-inf")
    for i in n:
        lar = max(lar, i)
    return lar

print(largest([1, 2, 5, 7, 7,4]))
```

### Time complexity = O(N)
### Space complexity = O(1)
