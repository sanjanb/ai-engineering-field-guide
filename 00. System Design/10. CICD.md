## What is CI/CD?

**CI/CD** (Continuous Integration & Continuous Delivery/Deployment) automates the software lifecycle from the moment a developer commits code to its final deployment in production. It minimizes manual intervention, allowing engineering teams to ship features faster and with higher confidence.

## 1. Continuous Integration (CI)

* **Core Practice:** Developers regularly push and merge code into a shared repository. Every push automatically triggers a build and test workflow on a CI server to ensure main branch stability.
* **The Testing Trade-Off:** Maintaining high test coverage catches more bugs, but longer test suites increase pipeline wait times and reduce developer velocity. Achieving the right balance is essential.

### CI Tooling Ecosystem

* **Source Control Management (SCM):** GitHub (stores source code, test scripts, and build configurations).
* **CI Orchestrators:** GitHub Actions, Buildkite, Jenkins, CircleCI, Travis CI.
* **Test Frameworks:** Jest (JS unit testing), Playwright & Cypress (e2e/integration testing).
* **Build Tools:** Gradle (Java), Webpack (JavaScript).

---

## 2. Continuous Deployment (CD)

Fully automated zero-downtime deployment varies significantly depending on system architecture:

### Stateless vs. Stateful Workloads

* **Stateless Systems:** Web servers and API tiers are well-suited for automated CD because instances carry no state, making rollbacks quick and low-risk.
* **Stateful Systems:** Database clusters, storage engines, and WebSocket servers carry high risk during schema or state changes. These usually follow a fixed release cadence and are managed by dedicated platform engineering teams.

### Risk Management Techniques

* **Feature Flags:** Decouples code deployment from feature exposure. Allows instant toggling of new features off in production without executing a full rollback.
* **Canary Deployments:** Routes new releases to a small subset of users (or internal staff) first to catch anomalies before expanding to the entire user base.

### CD Tooling

* **General Tools:** GitHub Actions, Buildkite, Jenkins.
* **Kubernetes/GitOps Deployment:** Argo CD.
